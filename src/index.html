คำถามที่อาจมี

นี่คือบริการที่ใช้งานจริงแล้วหรือยัง?

ยังเป็นต้นแบบทดสอบแนวคิด ไม่มีบัญชีผู้ใช้ ฐานข้อมูลออนไลน์ หรือระบบรับเงิน

ส่งข้อความหาลูกค้าให้อัตโนมัติไหม?

ไม่ส่ง คุณแก้ไข คัดลอก และตัดสินใจส่งผ่านช่องทางของคุณเอง

ข้อมูลตัวอย่างถูกเก็บที่ไหน?

ไฟล์ HTML แบบออฟไลน์เก็บข้อมูลในหน่วยความจำ รีเฟรชแล้วกลับเป็นข้อมูลสมมติ ส่วนห้องทดสอบ API เก็บในฐานข้อมูลภายในเครื่อง ห้ามใช้ข้อมูลลูกค้าจริงทั้งสองโหมด
