# ICP v0.1 — HYPOTHESIS
กลุ่มเดียว: ฟรีแลนซ์รับทำเว็บไซต์ในไทย ทำงานคนเดียว ดูแลทั้งงานขายและส่งมอบ
คัดเลือกทดลอง: ส่ง proposal >=5 ครั้ง/เดือน มีงานรอคำตอบ >=3 ราย และติดต่อผ่าน LINE หรืออีเมลเอง
ไม่รวมทีมขายองค์กร คนมี CRM ที่ใช้งานคล่อง และคนรับงานเฉพาะ marketplace ที่ไม่ควรติดต่อออกนอกแพลตฟอร์ม

JTBD: เมื่อส่งใบเสนอราคาแล้ว ฉันอยากรู้ว่าควรติดตามใครและพูดเรื่องใด เพื่อไม่ต้องเปิดหลายแชตย้อนหาเอง
Workflow สมมติ: รับ brief → ประเมิน → ทำใบเสนอราคาใน Docs/FlowAccount → ส่ง LINE/email → จดใน Sheet/Calendar หรือจำเอง → follow-up → won/lost
Pain สมมติ: จำวันไม่ได้ กลัวรบกวน ไม่รู้ next step กรอกซ้ำหลายที่
ทางเลือก: calendar, spreadsheet, existing CRM, daily sales ritual, ไม่ติดตามเลย
Buying trigger: จำนวนงานเปิดมากขึ้น; เคยพลาดรอบติดตามที่ระบุได้; ต้องการลดเวลางาน admin
Objections: เพิ่มงานกรอกข้อมูล, ไม่มี LINE sync, เครื่องมือฟรีทำได้, ข้อมูลลูกค้าอ่อนไหว, ยังไม่มีผลพิสูจน์
เหตุผลที่อาจจ่าย: ลดเวลาค้นแชตและช่วยให้ทำ follow-up ตามที่ตกลงไว้ — ต้องวัดจริง ห้ามสัญญาว่าเพิ่มยอดขาย
ช่องทางทดสอบ: คนรู้จักที่เจ้าของอนุญาต, กลุ่มฟรีแลนซ์ที่ผู้ดูแลอนุญาตโพสต์, opt-in demo
Value proposition ทดสอบ: “เปิดหน้าเดียว รู้ว่างานไหนควรติดตาม และมีข้อความเริ่มต้นที่ปรับเองได้”
